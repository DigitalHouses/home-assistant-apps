# Минимальный тест Zigbee-группы: реальные MQTT-состояния

**Дата:** 2026-10-21. **Цель:** проверить достаточно ли простых Z2M MQTT-сообщений
для диагностического дерева `выключатель → группа → участники`.
**Состояние:** инструкция, не результат домашнего E2E.

**В этом опыте НЕ строим Verification Engine, не шлём `/get` пачками,
не меняем настройки Z2M и не выполняем циклы питания.**

## Шаг 1 — read-only инвентаризация (начать здесь)

Home Assistant → **Настройки → Устройства и службы → MQTT → Настроить**
→ блок **«Слушать тему»** (Listen to a topic).

Ввести тему `zigbee2mqtt/bridge/groups` и нажать **Начать прослушивание**.
Если base topic изменён в настройках конкретного Zigbee2MQTT,
заменить `zigbee2mqtt` на него. В MQTT topic обычно сохраняется retained
JSON-массив вида:

```json
[
  {
    "id": 12,
    "friendly_name": "livingroom_spots",
    "members": [
      {"ieee_address": "0x00124b0012345678", "endpoint": 1}
    ]
  }
]
```

Это **пример**, не подтверждённая домашняя инвентаризация. Никаких публикаций в MQTT,
паролей или изменений настроек. Если вернулось `[]`, фиксируем
`NO_ZIGBEE_GROUP`; пока нечего подтверждать как настоящую группу.
Если не пришло вообще ничего — `NO_BRIDGE_DATA`, проверяем base topic
и подключение к MQTT. Пришедшее `Retain: true` — нормальный признак
*инвентаризации*, но не свидетельство о текущем состоянии ламп.

## Шаг 2 — один безопасный тест ON/OFF (только если есть настоящая группа)

1. Выбрать **некритическую** Zigbee-группу с 1–3 реальными,
   доступными и безопасно переключаемыми светильниками.
   Не выбирать цепи с оборудованием жизнеобеспечения, отоплением, охранным светом
   или устройствами Zigbee-инфраструктуры, которые нельзя прерывать.
2. Открыть MQTT **«Слушать тему»** с фильтром
   `zigbee2mqtt/#` (для выбранного base topic; на небольшом тестовом стенде),
   сохранить время и признак `Retain` для сообщений
   **группы и её участников**. Игнорировать посторонние сообщения.
3. Через **фронтенд Zigbee2MQTT** вручную нажать **OFF → ON** у группы.
   Обычная UI-команда; никакого MQTT `/set` из приложения или скриптов.
   Подождать 5–10 с после каждой команды; записать временную последовательность
   сообщений группы и каждого участника.
4. Повторить для одного *отдельного* светильника из группы, если это
   безопасно; сравнить групповой и индивидуальный пути.
5. Вернуть освещение в желаемое состояние. Сохранить результат:
   `base_topic`, group `id/friendly_name`, участники `IEEE/endpoint`,
   ожидаемое ON/OFF, таблица MQTT timestamps, `Retain`, исходные
   `state` payloads, `optimistic` настройки группы/ламп (если известны).
   Не отправлять скриншоты с паролями/сетевыми ключами.

## Интерпретация

- Зелёный статус HA/Z2M группы **не означает подтверждённого результата
  всех участников**. При `optimistic: true` Z2M может синтезировать
  изменение state для каждого участника.
- Сообщения отдельных ламп с новым `state` — полезное наблюдение, но
  **само MQTT-сообщение не доказывает**, что значение пришло из
  нового Zigbee ZCL-отчёта, а не из optimistic/cache.
- Если нет возможности доказать происхождение, в будущем дереве пишем
  `ON/OFF · наблюдается`, а не `подтверждено`.
- Только после результатов решаем, достаточно ли оставить состояние
  **«наблюдается / нет данных / конфликт»**, или конкретно эти модели
  требуют `optimistic=false` и точечных `/get`. Не делать
  общесетевых изменений ради одного опыта.
- Показание ваттметра — **независимый признак изменения мощности на
  измеряемой цепи**, а не индивидуальное подтверждение каждой лампы.

## Возвращаемые артефакты

Минимальный отчёт:

```text
BASE_TOPIC=
GROUP_ID=
GROUP_NAME=
MEMBERS=<N>
MQTT_GROUP_ON_OFF=<observed / not observed>
MQTT_MEMBERS_NEW_STATES=<N of N>
RETAINED_AFTER_COMMAND=<yes / no>
OPTIMISTIC_GROUP=<true / false / unknown>
OPTIMISTIC_MEMBERS=<true / false / unknown>
CONCLUSION=<simple_observed_is_enough / strict_proof_needed / insufficient_data>
```

**Если на домашнем Zigbee2MQTT нет реальных ламп/групп, честный итог
первого шага — «тест на реальной группе пока невозможен».**
Не считать виртуальные HA Template Light реальными Zigbee-группами.
