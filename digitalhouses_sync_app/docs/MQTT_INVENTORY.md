# DH Sync — реестр MQTT /sync

**Действующий контракт для DH Sync 0.5.1+.** Реестр продуктов формируется только из MQTT сообщений:

- `DigitalHouses/Global/+/sync`
- `DigitalHouses/Global/+/+/sync`

Публикация продукта: JSON по контракту DH Sync, QoS 1, retained.
Единственное правило допуска источника — GitHub owner `DigitalHouses`.

Нет белого списка продуктов, сравнения версии или проверки `availability`.
Поле `dashboard` определяет целевую панель для опубликованных Views.
Источником YAML является указанный в MQTT GitHub-репозиторий.

DH Sync при подключении заново читает retained-реестр брокера.
Локальный `product_sources.json` не загружается и не используется.
Пустая retained-публикация `/sync` удаляет соответствующую запись.
Ранее установленные YAML не используются для обнаружения продуктов и не
удаляются автоматически при исчезновении MQTT записи.
