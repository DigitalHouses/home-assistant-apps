# DigitalHouses Zigbee Monitor

Project ID: `dh_zigbee_monitor_app`

Home Assistant App for monitoring multiple Zigbee2MQTT instances, device availability, incidents, and MQTT message activity (including the top-spammers ranking).

## Planned scope

- Inventory of multiple Zigbee2MQTT networks and their devices.
- Detection of offline devices and recovery events.
- MQTT message activity ranking and anomalous reporting detection.
- Incident aggregation and Home Assistant notifications.
- No device passports or automatic healing in v0.1.0.

> Directory initialized. This is not yet an installable Home Assistant App.
